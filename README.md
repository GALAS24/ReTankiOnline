## 📖 О проекте

**ReTanki Online** — это амбициозная попытка воссоздать классический аркадный танковый экшен (вдохновленный ранними "Танками Онлайн" 2010–2014 годов) с использованием современного, производительного и строго типизированного стека. 

Мы отказались от устаревших плагинов (вроде Adobe Flash) в пользу чистого WebGL и WebSockets. Проект создается с упором на физику подвески, модульную архитектуру вооружения и динамический рендеринг.

## 🎨 Инновационная система красок (Custom WebGL Shader)

В ReTanki Online реализована сложная многослойная система рендеринга материалов. Краски — это не просто "натянутая картинка", это кастомный фрагментный шейдер (`AssetLoader.ts -> createArmorMaterial`), который динамически смешивает несколько слоев:

1. **Базовый паттерн (Paint Map):** Основная текстура краски (например, пиксельный камуфляж). Шейдер поддерживает изменение масштаба (`uPaintScale`) и угла поворота паттерна в реальном времени.
2. **Triplanar Mapping (Трехпланарное проецирование):** Для красок со сложным узором можно переключить режим маппинга (`uMappingMode`). Шейдер бесшовно проецирует текстуру по осям X, Y и Z, устраняя растяжения на углах башни и корпуса.
3. **Лайтмапы (Lightmap Ambient Occlusion):** Поверх краски накладывается запеченная карта теней. Это придает танку объем и подчеркивает геометрию без тяжелого реал-тайм освещения.
4. **Детализация (Details Map):** Независимый слой с альфа-каналом, содержащий царапины, заклепки, болты и вентиляционные решетки. Эти детали не закрашиваются паттерном краски, делая танк реалистичным.
5. **Процедурная грязь (Procedural Mud & Dirt):** Шейдер считывает локальную Y-координату модели. Чем ближе полигон к земле (гусеницы, днище), тем сильнее на него накладывается градиент процедурного шума грязи (`uMudStrength`). 
6. **PBR Материалы:** Краски реагируют на свет. Параметры `roughness` (шероховатость) и `metalness` (металличность) позволяют делать краски матовыми, глянцевыми или металлизированными.

## 🛠 Технологический стек

* **Frontend:** TypeScript, HTML5, CSS3
* **3D Графика:** [Three.js](https://threejs.org/) — рендеринг сцены, кастомные шейдеры, система частиц.
* **Физический движок:** [Rapier3D](https://rapier.rs/) (`@dimforge/rapier3d-compat`) — детерминированная физика, расчет массы, трения и лучевой (raycast) подвески танков.
* **Сеть (Backend & Client):** WebSockets (`ws`) — быстрый обмен данными с частотой (tickrate) 25-30 обновлений в секунду.
* **Сборка:** Vite (быстрый HMR для клиента) и Node.js (`tsx`) для сервера.

## 📂 Структура проекта и специализация файлов

Кодовая база строго разделена на клиентскую и серверную части, объединенные общими типами (`shared/`).

### 🎮 Клиентская часть (`client/src/`)

#### Ядро и Физика (`/physics`)
* **`TankPhysicsController.ts`** — Сердце управления танком. Создает физическое тело (`RigidBody`) корпуса и башни в Rapier. Рассчитывает лучевую подвеску (Raycast Suspension) для 12-16 точек гусениц, сцепление с дорогой, крутящий момент и применение модификаций (M0-M3).
* **`RemoteTank.ts`** — Представление танков других игроков. Получает интерполированные данные от сервера, двигает кинематическое тело, управляет вращением башни и синхронизирует визуальные эффекты (горение, заморозка).
* **`SpawnManager.ts`** — Парсер `.xml` карт. Находит точки спавна и дроп-зоны, проверяет физический пол карты, чтобы танки не проваливались под текстуры при возрождении.

#### Боевая система (`/combat`)
* **`WeaponManager.ts`** — Глобальный менеджер логики стрельбы. Управляет 9 видами пушек, расчетом урона, критическими попаданиями, эффектами (горение, лечение) и пересчетом ТТХ при смене грейдов (M0-M3).
* **`DropBoxManager.ts`** — Менеджер припасов (Двойной урон, Защита, Ускорение, Ремкомплект) и Золотых ящиков. 

#### Сеть (`/network`)
* **`NetworkManager.ts`** — Мост между локальной игрой и сервером. Собирает инпуты игрока (координаты, выстрелы, зажатие пробела для потокового оружия, переодевание танка) и отправляет на сервер.

#### Графика и Аудио (`/graphics`, `/audio`)
* **`AssetLoader.ts`** — Асинхронный загрузчик `.glb` моделей и ядро шейдерной системы красок.
* **`VFXManager.ts`** — Пул частиц (Billboard Particles) для взрывов, искр, дыма и трассеров выстрелов.
* **`AudioManager.ts`** — Пространственное аудио. Управляет звуками моторов, сиреной голда, звуками выстрелов и перезарядки.

### 🖥 Серверная часть (`server/src/`)
* **`index.ts`** — Точка входа сервера. Поднимает WebSocket-сервер на порту `8080`, обрабатывает новые подключения и маршрутизирует игроков.
* **`core/Room.ts`** — Авторитарная комната боя. Хранит эталонное состояние всех игроков, таймеры спавна ящиков и осуществляет широковещательную рассылку (`broadcast`) состояний мира (World Snapshot) всем клиентам.

## ⚙️ Как работать с кодовой базой

### 1. Добавление новой пушки
1. В `WeaponManager.ts` добавьте её ТТХ в константу `WEAPON_CONFIGS`.
2. В методе `executeDischarge` пропишите логику отдачи и вызова звука/вспышки.
3. Пропишите логику расчета попадания (Raycast для хитскана или ProjectilePool для летящих снарядов).

### 2. Настройка модификаций (M0-M3)
Характеристики динамически масштабируются с помощью `MOD_MULTIPLIERS` в `WeaponManager.ts` (например, M3 имеет множитель `1.60` относительно M0). 
Урон, перезарядка и максимальное ХП (вычисляемое из массы корпуса в `TankPhysicsController.ts`) пересчитываются автоматически при переодевании танка через метод `applyModifications`.

### 3. Редактор карт
В игру встроен `ZoneEditorUI` (вызывается на `F4` или `~`). Он позволяет визуально двигать точки спавна, ящики и голд-споты. При сохранении сервер автоматически перезаписывает хардкод-координаты в файлах `Room.ts` и `DropBoxManager.ts`.

## 🚀 Установка и запуск

Убедитесь, что у вас установлен **Node.js** (версия 18+).

### Шаг 1: Установка зависимостей
Откройте терминал в корневой папке проекта и выполните:
```bash
npm install
Шаг 2: Запуск сервера
Откройте первый терминал и запустите авторитарный сервер:

Bash
npm run dev
# Вывод: [Server] ReTanki Authoritative Server running on ws://localhost:8080
Шаг 3: Запуск клиента
Откройте второй терминал, перейдите в папку клиента и запустите Vite сборщик:

Bash
cd client
npm run dev
# Вывод: VITE v4.0.0 ready in 300 ms -> http://localhost:5173/
Откройте http://localhost:5173/ в браузере. Выберите пушку в гараже и нажмите "В БОЙ".
